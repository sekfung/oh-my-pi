# Use a Codex-inspired presentation with an independent Oh My Pi identity

The Desktop Application uses a compact, neutral workbench: a project and session sidebar, a centered virtualized transcript, a persistent pill composer, and an on-demand inspector for Changes, Files, Tasks, and Diagnostics. It uses React 19, Tailwind CSS 4, shadcn/ui primitives, Geist typography, semantic OKLCH tokens, compact ghost controls, and system, light, and dark appearance modes.

This is an Oh My Pi product, not a visual replica of Codex or Pi. It keeps the Oh My Pi name, iconography, terminology, capabilities, and interaction semantics. Files and Changes are read-only review surfaces with search and external-editor handoff; the application does not add a general code editor, file browser, or integrated terminal.
